# Sudha Rani Maddala · Portfolio

Personal portfolio of Sudha Rani Maddala, Data Scientist & AI/ML Engineer.

**Live:** https://sudhamsr.github.io

Built with Next.js (static export), deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

## Edit content

Almost everything on the page comes from `src/data/profile.ts` (profile, projects, skills, experience, education) and `src/data/knowledge.ts` (answers for the "Ask my CV" chat).

## Run locally

```bash
npm install
npm run dev   # http://localhost:3000
```
