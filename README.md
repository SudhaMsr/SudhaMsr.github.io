# Sudha Rani Maddala · Portfolio

Personal portfolio of Sudha Rani Maddala, Applied AI/ML Engineer & Data Scientist.

**Live:** https://sudhamsr.github.io

Built with Next.js (static export), deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

## Edit content

Almost everything on the page comes from `src/data/profile.ts` (profile, projects, skills, experience, education) and `src/data/knowledge.ts` (answers for the "Ask my CV" keyword search).

Rules for content: only claim what a repository, report or document supports. Featured projects (`featured: true`) need a `caseStudy` with the problem, contribution, architecture, measured results, what is **not yet measured**, and limitations. Do not add metrics that have not been measured.

## Rebuild the CV

`public/Sudha-Rani-Maddala-CV.pdf` is generated by `cv/build_cv.py`. Its content must match `src/data/profile.ts`, so update both together.

```bash
python3 -m venv .venv && .venv/bin/pip install -r cv/requirements.txt
.venv/bin/python cv/build_cv.py
```

## Run locally

```bash
npm install
npm run dev   # http://localhost:3000
```
